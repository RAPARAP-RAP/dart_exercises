Scenario
This program calculates a student's grade from a quiz score and checks if they passed. It demonstrates variables, data types, arithmetic and comparison operators, and formatted output in Dart.

How to Run
Run this command in your project folder:
dart run

Or paste the code into dartpad.dev then click Run.

Program Details

• String — Student name

• int — Quiz score and total items

• double — Grade percentage

• bool — Submission completion status and pass result

Operators Used

• Arithmetic: /  *

• Comparison: >=
