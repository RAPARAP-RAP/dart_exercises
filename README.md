# Dart Exercises — Grade Computation

This repository contains Dart programming exercises focused on calculating and computing student grades.

## What This Project Does
- Takes input for scores in different subjects or components
- Computes the average grade
- Converts numerical grades to letter grades (A, B, C, etc.)
- Displays the final result with a pass or fail status

## How to Run
1. Make sure you have Dart installed on your computer
2. Clone or download this repository
3. Open the project in your code editor
4. Run the program using:
   ```bash
   dart run bin/grade_calculator.dart
